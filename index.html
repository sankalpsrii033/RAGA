Architecture notes

            

              
Storage: JSON / Markdown technique cards + embeddings (vector DB). Path-based IDs e.g. rhymes/multisyllabic/chain_patterns.

              
Retrieval priority: ANTI_AI → GENRES+RHYMES+FLOW (high) → HOOKS/PUNCHLINES/WORDPLAY (mid) → THEMES/VOCABULARY (context) → RAP_DNA_PRESETS (seed).

              
Scale: Partition by top-level domain; shard embeddings per domain; version cards; never store full song lyrics.
